## 📝 Documentation Update Rules

### When Adding New Features
1. Update [API Reference](api/api-reference.md) if there are new APIs
2. Add documentation in the `features/` folder if needed
3. Update [Testing Guide](testing-guide.md) with new test cases
4. Update this file (documentation-index.md)

### When Changing Architecture
1. Update [Architecture](architecture.md)
2. Update [Technical Stack](technical-stack.md) if there are new technologies
3. Update related guides in `development/`
4. Update [Deployment Guide](deployment/deployment-guide.md) if needed

### When Adding New Tools
1. Update [Setup Guide](development/setup.md)
2. Update [Workflow](development/workflow.md) if it affects the process
3. Add to [Technical Stack](technical-stack.md)
